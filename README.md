# Java Editor（ブラウザで動く Java 学習用エディター）

インストール不要で、ブラウザだけで Java のコードを書いて、コンパイルして、実行できる学習用エディターです。
複数ファイルとパッケージ（フォルダ構造）にも対応しています。
コンパイルも実行も**利用者のブラウザ内**で行われ、書いたコードがサーバーに送信されることはありません。

**公開URL：** https://（アカウント名）.github.io/（リポジトリ名）/

Produced by Hidekazu Sato

## 主な機能

### 編集と実行
- Java のシンタックスハイライト、行番号、コード補完（Monaco Editor）
- 実行ボタン（または Ctrl+Enter）でコンパイルと実行
- 入力中のコードの文法エラー・型エラーに赤い波線を表示（マウスを乗せるとメッセージを表示）
- 標準入力（`Scanner`、`BufferedReader`）に対応
  - 入力欄に、実行前に1行ずつ値を書いておく方式です
  - コードが `System.in` を使っていないときは、入力欄は無効になります

### 複数ファイルとパッケージ
- **タブ**で複数のファイルを切り替えられます。「＋」でファイルを追加、「✎」で名前の変更、「×」で削除ができます。
- ファイル名を `util/MathUtil.java` のように付けると、フォルダ付きのファイルになります。新規作成時は、`package util;` を含むひな形が入ります。
- **「一覧」ボタン**で、左側にフォルダ構造のファイル一覧を表示できます。
  - フォルダは折りたたみができます。
  - 各行の右端の「×」で、ファイルの削除、またはフォルダごとの削除ができます（確認画面が出ます）。
  - エラーのあるファイルは、赤く表示されます。
- 同じ名前のファイルも、フォルダが違えば使えます（例：`a/Util.java` と `b/Util.java`）。
- 全ファイルをまとめてコンパイルします。エラーは、そのファイルのタブと波線に表示されます。

### 実行するクラスの選択
画面上部の「実行クラス」で、実行するクラスを選べます。

- **表示中のファイル（初期値）**：いま開いているタブのクラスを実行します。`main` がないファイルを開いているときは、`Main`（なければ `main` を持つ最初のクラス）を実行します。
- クラス名を直接選ぶと、タブを切り替えても、そのクラスを実行します。

### 保存と読み込み
| 操作 | 内容 |
|---|---|
| ファイルを保存（Ctrl+S） | 開いている1ファイルを `.java` として保存 |
| ファイルを開く | `.java` ファイルを1つ追加。`package` 宣言から、フォルダ位置を決めます |
| ZIPで保存 | 全ファイルを、フォルダ構造のまま `java-project.zip` に保存 |
| ZIPを開く | ZIP 内の `.java` をすべて読み込みます（現在のファイルはすべて置き換わります） |
| 新規プロジェクト | 現在のファイルをすべて破棄して、空の `Main.java` から始めます |

- ZIP を開くときは、ZIP 内のフォルダ配置に関わらず、各ファイルの `package` 宣言からフォルダ位置を決めます。Eclipse や IntelliJ の `src/main/java/…` 付きの ZIP でも、読み込めます。
- ZIP 内の `.java` 以外のファイルは、読み込まれません。
- 編集内容は、ブラウザにも自動保存されます（次に開いたときに復元されます）。

### サンプル
画面上部の「サンプルを選ぶ…」から、次のサンプルを選べます。選ぶと、現在のファイルはすべて置き換わります（確認画面が出ます）。

| サンプル | 内容 |
|---|---|
| 基本：合計 | 1から10の合計 |
| 繰り返し：FizzBuzz | 条件分岐と繰り返し |
| 入力：Scanner | 2つの整数を読み取って足し算（標準入力欄に値が自動で入ります） |
| 配列：平均と最高点 | 配列の合計、平均、最大値 |
| クラス：オブジェクト | 内部クラスとインスタンス |
| パッケージ：複数ファイル | `Main.java`、`util/MathUtil.java`、`app/Hello.java` |
| パッケージ：階層構造 | `com/example/app/` と `com/example/util/` の深い階層 |
| パッケージ：同名ファイル | `a/Util.java` と `b/Util.java`（同名で、フォルダが違う） |

## 使い方

1. 公開URLを開きます。
2. ステータスに「準備完了」と表示されるまで待ちます。**初回は十数秒から1分ほどかかります。**
3. コードを書いて、「実行」を押します。結果は画面下の「出力」に表示されます。
4. 入力が必要なプログラムは、実行前に左下の「標準入力」欄へ値を書いておきます。
5. 複数のファイルを使うときは、「＋」でファイルを追加するか、「一覧」を開いて構成を確認します。

### ファイル名のルール
- 使える文字は、英数字、`_`、`$` です。
- フォルダは `/` で区切り、末尾は `.java` にします（例：`util/Helper.java`）。
- 日本語のファイル名は使えません。

## 制限事項

- **Java 8 相当**の言語機能とクラスライブラリが対象です。
- 入力は実行前に書いておく方式です。プログラムの実行中に、対話的に入力することはできません。入力が足りないと `NoSuchElementException` などのエラーになります。
- Swing や JavaFX などの GUI アプリは対象外です。
- 実行中のプログラムを止めるボタンはありません。無限ループなどになった場合は、ページを再読み込みしてください。
- フォルダの位置と `package` 宣言が食い違っていても、エラーにはなりません（実際のパッケージは、`package` 宣言で決まります）。
- 最後の1ファイルは、削除できません。
- 編集内容はそのブラウザにだけ保存されます。別の端末やブラウザには引き継がれません。必要なときは、「ZIPで保存」でファイルに書き出してください。
- 初回の読み込み時に、Java の実行環境や各部品を取得するため、インターネット接続が必要です。学校のネットワークなどで外部への通信が制限されている場合は、動かないことがあります。

## 仕組み

- エディター：[Monaco Editor](https://github.com/microsoft/monaco-editor)
- Java 実行環境：[CheerpJ](https://cheerpj.com/)（Java をブラウザ上で動かす WebAssembly ベースの仕組み）
- コンパイラ：OpenJDK 8 の `javac`（`tools.jar`）を、CheerpJ 上でブラウザ内から実行
- ZIP の処理：[JSZip](https://stuk.github.io/jszip/)（「ZIPで保存」「ZIPを開く」を使うときに読み込みます）
- フォルダ構造の扱い：CheerpJ の `/str/` 領域にはフォルダを作れないため、コンパイルのたびに、小さな補助クラスがソースをフォルダ構造どおり `/files/__src/` に書き出してから、`javac` に渡しています。この方式が使えない環境では、フォルダを使わない方式に自動で切り替わります（その場合は、同名のファイルが使えなくなります）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（1ファイル完結） |
| `tools.jar` | OpenJDK 8 のコンパイラ（`javac`） |
| `serve.mjs` | 手元で動作確認するための簡易サーバー（任意） |

## 手元での動作確認

CheerpJ は、ファイルを直接開く方式（`file://`）では動きません。付属の簡易サーバーを使います（Node.js が必要です）。

```
node serve.mjs
```

起動後、ブラウザで http://localhost:8080/ を開きます。

## 公開（GitHub Pages）

1. リポジトリを Public にして、`index.html` と `tools.jar` を置きます。
2. Settings → Pages で、公開元を `main` ブランチの `/ (root)` にします。
3. 表示された URL を共有します。

`tools.jar` は、HTTP の Range リクエストに対応したサーバーから配信する必要があります。GitHub Pages のような一般的な静的ホスティングは、基本的に対応しています。

## 更新方法

`index.html` を修正したら、リポジトリに同名のファイルを上書きアップロードします。反映には数分かかります。画面が古いままのときは、Ctrl+F5 で強制再読み込みしてください。
